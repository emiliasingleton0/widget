# Mochi Desk Buddy v2.0
A windows desktop companion with pomodoro timer and to-do-list

## Run

```powershell
npm.cmd install
npm.cmd start
```

Or double-click `RUN-MOCHI.bat` after installing dependencies.

## Build a Windows installer

```powershell
npm.cmd run build:installer
```

The installer is written to `dist`.

## Notes

Windows may warn about locally built unsigned applications
